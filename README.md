# Causal Audits of Skin-Lesion Classifiers: manuscript versions

This repository keeps successive versions of the manuscript
"An Identification Ladder for Causal Auditing of Skin-Lesion Classifiers:
Performed Artifact Edits and Concept Components" and its supplementary material.

- `paper/paper5.md`: main text
- `paper/supplementary5.md`: supplementary material
- `paper/figures/`: figures referenced by the two texts (author photos are not included)

Code, cached results and checkpoints are in
https://github.com/dqtoan87/Causal_Audits_of_SLC_v2 (the commit pinned in the text).
Each commit here is one revision; see the commit history for the sequence.
